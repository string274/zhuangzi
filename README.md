# 基于词性标注序列因果语言模型的《庄子》内外杂篇风格计量研究

本仓库是论文《基于词性标注序列因果语言模型的〈庄子〉内外杂篇风格计量研究》的配套分析代码，作者：刘士瑄。

研究以郭象传世本《庄子》为语料，将文本转换为细粒度词性（POS）序列，构建轻量化因果语言模型（Causal-LM），并与“功能词 + SVM”“POS 2-gram + SVM”两组基线实验对照，用于考察《庄子》内篇、外篇、杂篇之间以及篇目内部的风格差异。

> 注意：本仓库主要提供方法代码与复现流程。原始语料受第三方语料库使用条款约束，不随仓库分发。

## 研究问题

1. 词性序列（POS）能否有效表征《庄子》的篇章风格？
2. 轻量化因果语言模型能否适配小样本、高稀疏度的上古汉语语料？
3. 在功能词、POS 2-gram 与完整 POS 序列三类特征中，哪一类更能反映《庄子》内外杂篇的作者风格差异？

## 方法概要

- **EXP1：功能词 + SVM**  
  选取人称代词、助动词、介词、连词、副词、句末语气词等 20 个功能词，计算相对词频，使用 One-Class SVM 与余弦距离进行风格判别。

- **EXP2：POS 2-gram + SVM**  
  从纯 POS 序列中提取二元词性标记串，过滤低频组合后使用 SVM 与余弦距离进行判别。

- **EXP3：完整 POS 序列 + Causal-LM**  
  使用 Transformer 纯解码器架构的轻量因果语言模型学习内篇 POS 序列生成规律，以外杂篇切片为测试对象，计算困惑度（PPL）与隐藏层余弦距离，并归一化为综合指标 `Dstyle`。

- **滑动窗口**：每个子样本 256 词，相邻子样本重叠 128 词；滑动窗口仅在篇章内部使用。
- **内篇一致性检验**：篇章级留一法交叉验证。
- **阈值设定**：PPL 与余弦距离采用 `μ + 2σ`；SVM 决策分数采用 `μ - 2σ`；`Dstyle` 以对内篇经验分布 95% 分位数 `Dcrit = 2.487` 为临界值。
